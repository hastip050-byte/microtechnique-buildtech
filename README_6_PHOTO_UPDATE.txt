MICROTECHNIQUE BUILDTECH — FULL SOURCE PACKAGE (6 PHOTO GALLERY)

This is a clean source package with the 6-photo property gallery update integrated.

INCLUDED
- Full project source from the provided Microtechnique_Buildtech_Complete archive
- Updated public/app.js, public/style.css and src/server.js
- Separate illustrative photos for the four sample/demo property types
- Owner/Builder photo upload (maximum 6 photos per property)
- Property card cover photo and detail-page gallery

NOT INCLUDED
- node_modules (run npm install)
- Local SQLite database and session files (local property/user data is not included)
- .env secrets (configure using .env.example)

FRESH SETUP
1. Extract this ZIP.
2. Open the extracted Microtechnique_Buildtech_Complete folder in VS Code.
3. Use Node.js 24.x.
4. Run: npm install
5. Configure .env using .env.example.
6. Run: npm start
7. Open the local site and hard-refresh with Ctrl+F5.

SAFE UPDATE TO AN EXISTING PROJECT
Do not replace your existing data/buildtech.db or .env.
Back up public/app.js, public/style.css and src/server.js first.
Copy updated public/ and src/ from this package into your existing project root and merge the included public/assets images. Keep your database and existing assets.

DEMO IMAGE NOTICE
Sample/demo property images are illustrative placeholders and do not represent verified listings.

VALIDATION
JavaScript syntax checked with node --check. A browser end-to-end test against your local database has not been performed.
